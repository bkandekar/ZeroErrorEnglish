ℹ️ How Scheduling Works

  1. When you click Schedule Post, the file is saved in /posts/ with status: "scheduled" and your future date/time.
  2. GitHub Actions automatically runs build.js every 30 minutes.
  3. When the scheduled time is reached, GitHub Actions auto-publishes the post, regenerates posts-index.json, and updates GitHub Pages without touching code!
